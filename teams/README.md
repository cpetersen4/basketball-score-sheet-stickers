# Team files

Create one folder per team here, for example `teams/my-team/`:

```text
my-team/
├── roster.csv
└── stickers.pdf
```

Import the roster into the app, review the names and numbers, and save the PDF alongside it. The Save dialog starts in the imported roster’s folder. Manual entry lets you choose any output folder.

Real team folders and their contents are ignored by Git. Only this README and the fictional `sample/` folder are tracked. Copy `sample/team-names_sample.csv` into your team folder to get started. Do not put real names in the tracked sample folder.
